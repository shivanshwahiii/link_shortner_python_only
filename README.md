# URL Shortener (Python CLI)

A simple command-line URL shortener built with Python.  
Implements full **CRUD operations** (Create, Read, Update, Delete) along with persistent storage, click tracking, and search functionality.

## Features
- Create: Shorten URLs with random or custom codes
- Read: Expand short URLs and view statistics
- Update: Track and increment click counts automatically
- Delete: Remove short URLs from storage
- Search stored URLs by keyword
- Menu-driven CLI interface
